## Схема подключения

Для корректного функционирования модуля необходимо выполнить следующие соединения:

1. Подключите интерфейс CAN модуля к порту CAN1 полётного контроллера с помощью соответствующего кабеля .

2. При использовании второго CAN-порта для резервирования или подключения дополнительных устройств аналогично подключите его к CAN2.

3. Подключите силовые провода модуля к батарее согласно маркировке IN/OUT на корпусе устройства .

4. Убедитесь, что на конце CAN-шины установлен терминальный резистор 120 Ом (если модуль является последним в цепи) .

## Настройка прошивки полётного контроллера

Перед началом настройки убедитесь, что полётный контроллер использует актуальную версию прошивки с поддержкой DroneCAN:

-  **ArduPilot**: версия AC3.6/AP3.9 или выше

-  **PX4**: версия 1.10 или выше

## Конфигурация параметров

### Для прошивки ArduPilot

Подключите полётный контроллер к наземной станции управления (QGroundControl или Mission Planner) и установите следующие параметры :

| Параметр        | Значение | Описание                                                  |
|-----------------|----------|-----------------------------------------------------------|
| `CAN_P1_DRIVER` | 1        | Включение драйвера CAN на порту 1                         |
| `CAN_P2_DRIVER` | 1        | Включение драйвера CAN на порту 2 (если используется)     |
| `BATT_MONITOR`  | 8        | Выбор типа монитора батареи -- DroneCAN                   |
| `BATT_OPTIONS`  | 1        | Игнорирование поля State Of Charge для DroneCAN-мониторов |

После записи параметров отключите питание и выполните перезагрузку полётного контроллера .

**Для ArduPilot (Mission Planner)**:

1. Перейдите в раздел Configuration -> Optional Hardware -> DroneCAN/UAVCAN

2. Нажмите mavlink-can1 (при подключении к CAN1)

3. Найдите параметры модуля в отобразившейся таблице

4. Внесите изменения и нажмите Write Params -> Commit Params

**Для PX4 (QGroundControl)**:

1. Откройте Analyze Tools -> MAVlink Console

2. Выполните `uavcan status` для получения NODE ID модуля

3. Для изменения параметра используйте команду: `uavcan param set [ID] [param_name] [value]`

4. Сохраните изменения: `uavcan param save [ID]`

## Калибровка измерений

Для повышения точности измерений напряжения и тока доступна калибровка параметров :

| Параметр         | Описание                              |
|------------------|---------------------------------------|
| `BAT_AMP_PERVLT` | Коэффициент преобразования тока       |
| `BAT_VOLT_MULT`  | Коэффициент преобразования напряжения |

**Порядок калибровки**:

1. Подключите модуль к CAN1 полётного контроллера с прошивкой ArduPilot

2. В Mission Planner перейдите в SETUP -> Optional Hardware -> DroneCAN/UAVCAN -> MAVlink-CAN1 -> Parameters

3. Сравните отображаемые значения напряжения/тока с показаниями эталонного прибора

4. При необходимости скорректируйте параметры `BAT_AMP_PERVLT` и `BAT_VOLT_MULT`

5. Сохраните изменения и перезапустите контроллер
